**VibeCheck**

VibeCheck is a Python-based CLI application built entirely using Object-Oriented Programming (OOP) principles. It simulates a decentralized campus social network directly in the terminal.

Features

*  Anonymous Posting — Randomized aliases for confessions and polls.
*  Hashtags — Categorize posts using tags like #exams, #hostellife, and #food.
*  Interactive Polls — Vote on polls with dynamic percentage bars.
*  Community Engagement — Like posts and add comments.
*  Dynamic Feed — Supports chronological and trending-based sorting.
*  JSON Persistence — Saves and restores data using vibes.json without a database.
*  OOP Design — Uses classes, inheritance, composition, and polymorphism.

Tech Stack

* Language: Python
* Interface: Command Line (CLI)
* Storage: JSON
* Concepts: OOP, Inheritance, Polymorphism, Composition
